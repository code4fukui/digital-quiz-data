# digital-quiz-data

このリポジトリには、Webベースのデジタル学習クイズ用のCSVデータが含まれています。

## デモ

このデータを使用したサンプルアプリケーションは以下で公開されています:
https://github.com/code4fukui/digital-quiz/

## データ構造

メインのインデックスファイルである [list.csv](list.csv) には、利用可能なすべてのクイズデータファイルのリストが含まれています。

初期データセット `ap-2021spring.csv` には、令和3年度春期 応用情報技術者試験（AP）から転記された5問が含まれています。

## 出典

データの出典は以下の通りです:
[IPA (情報処理推進機構): 問題冊子・配点割合・解答例・採点講評 (2021年、令和3年4月)](https://www.jitec.ipa.go.jp/1_04hanni_sukiru/mondai_kaitou_2021r03.html)
